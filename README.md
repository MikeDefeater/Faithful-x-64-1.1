# Classic Faithful 64x Jappa + Addon (Minecraft 1.21.10)

Zwei Resourcepacks für **Minecraft Java 1.21.10**:

| Datei | Was ist das? |
|---|---|
| `Classic-Faithful-64x-Jappa-1.21.10.zip` | Das Grundpack **Classic Faithful 64x Jappa** vom Faithful-Team (unverändert) |
| `Classic-Faithful-64x-Jappa-1.21.10-Addon-64px-1.1.zip` | Addon mit 64px-Texturen für viele Mods (Create, AE2, Ars Nouveau, Twilight Forest u. v. m.) |

## Download

Es gibt zwei Versionen. Unter „Assets“ jeweils **beide** ZIP-Dateien herunterladen:

- 👉 **[64x (Release v1.1)](../../releases/tag/v1.1)**: volle Auflösung, schönste Optik
- 👉 **[32x (Release v1.1-32x)](../../releases/tag/v1.1-32x)**: für schwächere PCs, läuft flüssiger. Beide Packs wurden automatisch von 64x auf 32x verkleinert.

Nimm entweder die 64x- **oder** die 32x-Version, nicht beide gemischt.

## Installation

1. Beide ZIP-Dateien herunterladen. **Nicht entpacken!**
2. Minecraft starten → **Optionen** → **Ressourcenpakete** → **Pack-Ordner öffnen**.
   (Der Ordner ist normalerweise `%appdata%\.minecraft\resourcepacks`. Bei Launchern wie CurseForge oder Prism liegt er im Ordner der jeweiligen Instanz.)
3. Beide ZIP-Dateien in diesen Ordner kopieren.
4. In Minecraft beide Packs nach rechts („Ausgewählt“) schieben, und zwar in dieser Reihenfolge:
   - **oben:** das Addon
   - **darunter:** Classic Faithful 64x Jappa
5. **Fertig** klicken.

Tipp: 64x-Texturen brauchen mehr Grafikspeicher. Wenn das Spiel ruckelt, hilft es, Minecraft mehr Arbeitsspeicher zu geben.
